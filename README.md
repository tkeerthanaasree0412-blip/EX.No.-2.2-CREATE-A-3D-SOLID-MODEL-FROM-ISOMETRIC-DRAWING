# EX.No.-2.2 CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date :

## AIM: 

To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

1. Open Autodesk Fusion 360 and create a new design. Set the units to millimetres (mm).

2. Select the XY Plane and create a sketch.

<img width="507" height="568" alt="Screenshot 2026-11-08 233147" src="https://github.com/user-attachments/assets/a66ca2ad-32f4-4737-9714-ed8ed4ae8521" />

3. Draw a rectangular slot-shaped base using a rectangle and two semicircular ends of radius 18 mm. Maintain an overall length of 66 mm and a width of 36 mm.

<img width="882" height="457" alt="Screenshot 2026-11-08 233640" src="https://github.com/user-attachments/assets/597ceeb0-5854-4347-91aa-498e0cdd25dc" />

4. Finish the sketch and use the Extrude tool to give the base plate a thickness of 10 mm.

<img width="503" height="605" alt="Screenshot 2026-11-03 211338" src="https://github.com/user-attachments/assets/581e2850-9995-4327-98f9-3d88cf7d5838" />

5.Use the hole option to make two holes of radius 16mm.

<img width="536" height="712" alt="Screenshot 2026-11-08 234706" src="https://github.com/user-attachments/assets/c107d7e4-49ce-4e56-9b53-61fd0e2076a7" />

6. Select the top face of the base and create a rectangular sketch for the vertical support. Use the given dimensions of the drawing and extrude it vertically to a height of 28 mm.

7. On the top of the vertical support, create a rectangular sketch for the horizontal arm with a length of 40 mm and extrude it to a thickness of 10 mm.

8. Create the inclined triangular supporting rib between the base plate and the horizontal arm using the Sketch tool on the appropriate side plane. Draw the triangular profile and extrude it to form the inclined support.

9. On the free end of the horizontal arm, create two concentric circles with outer diameter 30 mm and inner diameter 20 mm.

<img width="363" height="461" alt="image" src="https://github.com/user-attachments/assets/e7b564b1-ecd6-48f9-a6eb-172db6087cff" />

10. Finish the sketch and extrude the circular profile by 10 mm to form the cylindrical boss with a central hole.

<img width="201" height="170" alt="Screenshot 2026-10-11 174217" src="https://github.com/user-attachments/assets/75e6fb72-9b67-4264-84b8-f51cf2e81843" />

11. Use the Join operation wherever necessary to combine the individual features into a single solid body.

12. Finally, use Create Drawing to convert the completed 3D model into a 2D engineering drawing with the required front, top and isometric views.

<img width="284" height="453" alt="Screenshot 2026-10-11 172436" src="https://github.com/user-attachments/assets/9584dc60-7623-44ec-ab8a-c9d028a98b72" />

13. Save the completed design.
